# 🌱 Plant Monitor

A custom ESP32-based PCB project for monitoring plant conditions.

The goal of this project is to build a device that can measure:
- 🌡️ Temperature
- 💧 Humidity
- 🌱 Soil moisture

The measurements will be shown on an OLED display, with LEDs providing additional status information.

## 🎯 Project Goal

I want to design and build a custom PCB using an ESP32.

The PCB will connect:
- ESP32
- BME280
- I²C OLED
- Soil-moisture sensor
- Green status LED
- Red status LED
