#  Plant Monitor PCB:-
It is a custom ESP32-based PCB project for monitoring plant conditions.

This PCB can measure:
-  Temperature
-  Humidity
-  Soil moisture

The measurements will be shown on an OLED display, with LEDs providing additional status information about the soil.
